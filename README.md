Start with the [G4 definition](definition/engineering-287/definition/PE-PROTOCOL-SPECIFICATION-G4.candidate.md), the [reviewed file inventory](FILES.tsv) and the [licensing scope](docs/LICENSING.md). This export contains the 89 defining texts and their inventory and licence files.
